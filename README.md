# betternotes

## USAGE

# CONTROL PANEL

0. What is a SESSION - It's where you work notes will be stored. Think of it as a bucket or a box or whatever.

1. Create a session - Fill up the text field with your desired session name and then click create session button below it.

2. Current Session - it shows which session is the active one.
   Note : Always check the current session to make sure you are saving the worknotes in the proper session

3. Sessions List - Click the name of the session to switch which session you want to use. It should reflect via the Current Session text.

4. Session Records : Export - Will export all your worknotes in the particular session you clicked. File format is a plain/text format.

# NOTE

1.  All text fields must be filled up.

2.  Always Click SAVE after finishing your note.
    2a. Clicking Save will copy the note work format into your clipboard. Try CTRL + V on an empty note for clarity.

3.  Cancel Button - Will erase all the data in the fields, clicking this without saving will result in data loss. Will ask for
    confirmation before cancelling.

4.  New note - Will sync your notes to the localStorage its important you click this after saving.
